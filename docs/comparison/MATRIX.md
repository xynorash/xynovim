## How to read it

- **Status** is one of `ahead`, `tied`, `behind`, `unknown`, or `n/a` (an internal engineering item with no competitor counterpart; its done/not-done state is in the "xynovim" cell). `ahead` is written only where a cited page, source file or measurement shows the others lack the thing or do it worse. Silence of a docs page is recorded as "not documented", which is weaker than "absent", and such a row is **not** `ahead` unless it says "by documentation".
- Labels: **[m]** measured on this machine (AMD Ryzen 7 5800X, Linux 7.3.3, Neovim 0.12.6, rust-analyzer 1.99.1); **[pub]** published claim, not reproduced; **[src]** read from a product's source file or docs on the retrieval date; **[inf]** my inference, flagged as such.
- Competitor columns: **RR** RustRover, **VSC** VS Code with rust-analyzer, **Zed**, **Hx** Helix, **NvCfg** LazyVim / AstroNvim / NvChad / kickstart / rustaceanvim. "n/d" = not documented on the pages read; "n/f" = not found this pass.
- No competitor product was installed or run (licence for RR; installs and downloads are forbidden here). Everything about them is from docs, release notes, source files read with `gh api`, and search. Reddit is unreachable and was not used.
- "Next step" for a `behind` row is either an issue-ready description (what to change, where, the test that proves it) or **structural** with the reason. Every row dated 2026-11-12 unless it says otherwise.
